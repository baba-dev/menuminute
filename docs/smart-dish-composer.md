# PR B — Smart Dish Composer

The Menu Studio's Add Dishes and Find in Menu controls are separate modes. Category-level Add Dish opens the shared Composer with that category selected and search focused. Multi-select stages entries privately; Review & Add requires explicit prices (or explicit Free), section and optional approved photo. A batch is validated and applied to the in-memory draft atomically; the existing Save and Publish commands remain deliberate. A manual custom dish is always possible. Adding a new section in review is an explicit choice.

The outlet's existing dish matches show their already-assigned photograph only if the file is ready and approved. Since newly uploaded photographs have no name association, review displays the authenticated outlet-scoped approved upload gallery for explicit selection, including a preview beside the dish. Other outlets' files, unapproved uploads and editorial artwork are never auto-attached. The full editor for variants, add-ons, schedules and media stays available. No database migration, AI provider call or public media contract changes.
