# Food Encyclopedia P1 — The Atlas

**Issue:** #363 · **Design:** https://www.figma.com/design/LNd5ZhhFjbXrD8T4stV24m · **Base:** `17f003d5bf440c4452c30ddd3f93002b14a6f4ee`.

## Scope

Add an isolated `/explore` public editorial UI faithful to the selected Atlas design, with responsive light/dark layouts for home, browse, a dish, an ingredient, a cuisine, a comparison, and search. No new dependencies. Reuse MenuMinute's existing Bricolage Grotesque and DM Sans fonts and already-present approved dish images; never imply an approved artwork is evidence of ingredients or safety.

## Editorial gates

Every included pilot profile is a **preview**. No preview article is search-indexable, advertised in a published-entry sitemap, or displayed as verified professional advice. The pilot showcases the UI while real source research, human editorial review, rights verification and a publish/rollback workflow are developed. Do not call sample profiles researched, nutrition-verified, allergen-safe or restaurant-confirmed. `isEditoriallyIndexable` requires `published` plus reviewer, review timestamp, publication timestamp and sources. Existing `dish-catalogue.json` is suggestions-only and MUST NOT be bulk-published.

The public UI is read-only and has no tenant data, no AI providers, no third-party search service, and no payments. Publishing to a durable editorial database / staff editor is **subsequent reviewed work**, not a claim of this UI PR. This avoids mixing tenant RLS or production migrations into a design rollout.

## Ads and privacy

AdSense component is implemented as **off by default** and never emits a third-party script unless a future independent integration meets site approval, regional consent/CMP, route exclusions and performance/CLS tests. The search screen and restaurant transactional routes must remain ad-free. No empty simulated inventory in production.

## Routes

- `/explore`
- `/explore/browse`
- `/explore/search?q=...` (noindex)
- `/explore/dishes/[slug]`
- `/explore/ingredients/[slug]`
- `/explore/cuisines/[slug]`
- `/explore/compare/[slug]`
- `/explore/terms/[slug]` (future content)

All unknown routes return 404. Preview article metadata must set `robots.index=false`; the dedicated encyclopedia sitemap includes only canonical indexable records. On editorial release, confirm official external citations, original author/source metadata, accessible article images and consent before enabling indexing or advertising.

## Acceptance and rollback

Verify 320, 360, 390, 430, 768, 1024 and 1440 px; theme switching; keyboard nav; labels; image fallbacks; no leaking private tenant data; bounded search; and no ads on any operational route. CI must run lint, typecheck, tests and production build against the final SHA on Linux ARM64. No server or app-wide dependency changes. Rollback is the previous compatible web release; this slice has no destructive migrations or new secrets.
