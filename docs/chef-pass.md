# Marketing Section 5 — The Chef's Pass

Original approved MenuMinute illustration for the public homepage. This is a *planned Kitchen Pro experience*, not a production KDS, and its tickets/states are static review fixtures. The section follows the live homepage Order Conveyor and precedes product comparisons.

- The four embedded SVGs are the original approved 1440×790 dark/light and separately composed 430×900 portrait dark/light assets. Their strings are trusted compile-time literals, have no scripts, external images, external network calls or user content, and are scoped to this marketing component.
- The deterministic 8.5-second illustration preserves independent Grill/Tandoor/Drinks progression and an authorized expeditor's explicit final confirmation: Drinks completes first, Grill next, Tandoor last. Partial station work never causes the illustrative whole order to be released.
- Initial/SSR/no-JavaScript and reduced-motion renders have the complete final-state illustration. Desktop motion begins on entering the viewport, pauses offscreen or with a hidden document, resumes without catch-up, and offers working Pause/Play/Replay. Mobile uses the separately designed static portrait illustration for legibility.
- Theme variants follow the global resolved `data-theme` and preserve the existing Ink & Ember palette. Section copy truthfully says Kitchen Pro is in development and links to the existing pricing information and free manual QR menu onboarding.
- There is no live API integration, kitchen route replacement, AI, sound, order action, paid entitlement or schema migration. Phase 5's complete KDS and expeditor release gates remain independent.
- CI must pass final-head formatting, ESLint, strict TypeScript, PostgreSQL/Redis integration, ARM64 production build/Playwright and aggregate gate. Production requires exact-SHA publisher, stage, activation and public-readiness verification; merge alone is not production deployment.
