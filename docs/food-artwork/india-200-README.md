# Menu-Minute: India 200 dish illustration backlog

This is a **curated editorial shortlist** of 200 *new* illustration candidates for the next original Ink & Ember food-artwork batches. The `MM-IN-001`–`MM-IN-200` identifiers are stable production IDs, **not a measured India-wide popularity or sales ranking**. Regional associations indicate where the food is strongly associated, not exclusive ownership or proven birthplace.

## Files

- [CSV](india-200-dish-backlog.csv): easy to filter, sort and import in a spreadsheet.
- [JSON](india-200-dish-backlog.json): application/production pipeline ingestion, including the explicit 36-item exclusion set.
- [Validator](../../scripts/food-artwork/verify-india-backlog.mjs): checks total, consistency, uniqueness, excluded artwork and basic metadata.

## Field definitions

| Field | Meaning |
|---|---|
| `id` | Stable dataset sequence ID, never a popularity rank |
| `dish_name` | Canonical English display name for this illustration task |
| `slug` | Unique filename/key, e.g. `palak-paneer` |
| `collection` | Illustration-production batch / broad region |
| `regional_association` | Search/curation hint, not exclusive historical origin |
| `category` | Typical presentation role: main, snack, starter, combo, side, soup, breakfast, street_food, bread, dessert |
| `dietary_hint` | Provisional recipe-type hint only: vegetarian, non_vegetarian, egg, varies |
| `visual_anchor` | Distinctive food appearance to prevent generic/wrong images |
| `illustration_status` | `not_created` for all 200 new candidate assets |

**Safety of menu claims:** The dietary field is NOT merchant-approved vegetarian/vegan, allergen, halal, kosher, gluten-free or cross-contact metadata. Those depend on a restaurant's actual recipe and processes and must be verified by the owner. Examples with variable traditional recipes are explicitly marked `varies`.

## Art direction for future artwork (not generated by this data PR)

- Match the approved original illustrated-dish sheets, with warm flat colors, bold outlines and food-specific details; avoid tracing photographs or presenting generic stock imagery as a real dish photo.
- Create separate transparent background files, review dark/light surfaces `#111111` / `#FFFFFF` and watch contours of pale foods.
- Use `visual_anchor` to distinguish dish presentation, with no printed text in the artwork; name and accessibility text remain application metadata.
- Never replace a restaurant owner's chosen/uploaded media without their action. No runtime menu changes in this PR.
- Keep `illustration_status=not_created` until an image is actually reviewed and shipped. Rendered AI concept sheets are not inherently editable SVG paths.
