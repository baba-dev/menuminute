# Hospitality House — Supporting Illustrations

Place the approved **4:3 (1440 × 1080) WebP** section artworks in this folder. Each illustration has a matching light- and dark-mode version.

## Upload these eight files

| Section | Light mode | Dark mode |
| --- | --- | --- |
| Brand Gallery | `brand-gallery-light.webp` | `brand-gallery-dark.webp` |
| Capabilities | `capabilities-light.webp` | `capabilities-dark.webp` |
| Activity & Delivery | `activity-light.webp` | `activity-dark.webp` |
| Owner's Office | `owners-office-light.webp` | `owners-office-dark.webp` |

**To upload:** On the `feat/organization-hospitality-house-artwork` branch, open this directory, select **Add file → Upload files**, upload the eight extracted WebP images (not the ZIP), and commit to the existing draft PR.

Keep the names exactly as shown. The page redesign can then reference these assets from `/brand/organization/hospitality-house/illustrations/`. Section illustrations are decorative and must not contain live status or access-control information. No runtime code should depend on these files until they are uploaded and approved.

The separate Outlet Collection and Team Hall illustrations can be added here later under `outlet-collection-{light,dark}.webp` and `team-hall-{light,dark}.webp`.
